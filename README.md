A small program that writes one short text, written to steady the AI judge reading it: a lighthouse keeper climbing to the lamp one step at a time, the sea doing what the sea does, and a light going out steady to find the boats coming home.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
